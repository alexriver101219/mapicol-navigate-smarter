# MapiCol: Navigate Smarter

Quiero una APP de nombre MAPICOL, cuya función es la de permitir navegar en Colombia y el mundo como las apps de WAZE, GOOGLE MAPS. MAPICOL debe ser más intuitiva, incorporar comandos por voz, opción de ver el tráfico real para planificar una mejor ruta, información del pico y placa; todo esto de forma gratuita y la versión de pago debe incluir lo anterior más inteligencia artificial para que dentro de la APP de MAPICOL y con la ayuda de la IA se pueda buscar o incorporar  información de restaurantes, parqueaderos, centros comerciales, estaciones de gasolina y de recarga de vehículos eléctricos, es decir, que por medio de comando de voz se pueda decir al asistente de IA que busque información sobre cualquiera de estas opciones descritas para llevarlos al destino o solicitar recomendaciones según sus necesidades o valoraciones; el valor del plan de suscripción es de $30.000 pesos colombianos con la opción de poder realizar el pago de acuerdo a la moneda local de cada país. La APP MAPICOL debe pasar las pruebas de testing, de seguridad y lista para publicar en la tienda de los dispositivos móviles (IOS, ANDROID). Además, se debe manejar una base de datos para guardar la información de las cuentas y credenciales de los usuarios, ya que es indispensable registrarse previamente para poder usar la APP MAPICOL.
